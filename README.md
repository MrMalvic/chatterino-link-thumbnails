# Link Thumbnails

Image links in chat show up as images. Click one to open it.

## Install

1. Put this folder in your Chatterino `Plugins` folder:
   - Linux: `~/.local/share/chatterino/Plugins`
   - Windows: `%APPDATA%\Chatterino2\Plugins`
   - macOS: `~/Library/Application Support/chatterino/Plugins`
2. Settings → Plugins → enable **Link Thumbnails**

Needs a recent nightly build. Stable 2.5.5 won't work.

## Which links?

- Image sites like imgur, kappa.lol, gyazo, catbox
- Links ending in `.png` `.jpg` `.gif` `.webp`

Add more sites to `HOSTS` in `init.lua`.
